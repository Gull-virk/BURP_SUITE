# 📖 About

**Burp Suite Custom Tool** is an educational project created to explore Python application structure and user interface design inspired by web security testing workflows. It is intended for learning, experimentation, and authorized security research in controlled environments.

# 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Gull-virk/BURP_SUITE.git
```

Move into the project directory:

```bash
cd BURP_SUITE
```

Install the required packages:

```bash
pip install -r requirements.txt
```
